## P0 — Тихие обновления (довести до ума)
Порядок важен: сначала подпись, потом per-user.

1. **Подпись установщика и .exe (Authenticode).** Убирает SmartScreen и «Издатель: неизвестен» в UAC; без неё любой тихий/фоновый апдейт вызывает подозрение ОС. Сертификат (OV/EV) → секрет `WINDOWS_PFX_BASE64` в CI (шаги `Sign executable`/`Sign installer` уже готовы). — *также закрывает HIGH из ревью.*
2. **Независимая проверка апдейта.** Сверять Authenticode-подпись скачанного `.exe` перед запуском (`WinVerifyTrust`/встроенный ключ) — сейчас доверие держится только на GitHub-digest; при компрометации репо/CI → тихий admin-RCE.
3. **Per-user установка + фоновое обновление** (вернуть `fc1bb53`, доработать). Тест на живой Windows: тихая установка без UAC, миграция/сосуществование со старой Program Files-копией, перезапуск. Явно решить миграцию (оставлять старую копию для отката vs. снимать).

## Находки ревью (дыры/баги/оптимизация)

### Исправлено (эта итерация)
- `open_ftp_workspace`: `create_ftp_workspace` вне try → 500 при сбое диска/прав → теперь `state.error`+303.
- Скрытый поллер `/api/update/job` после закрытия «Настроек» → отменяется по токену `settingsOpenId`.
- CR/LF в именах файлов FTP (инъекция в `RETR`/`MDTM`) → отсекаются в `_ftp_list_entries`.
- `ValueError`/`LimitOverrunError` из баннера discovery → 500 → теперь ловятся.
- Затенение модуля `config` локальной переменной в роутах FTP → переименовано.

### Открыто (крупное — в P0/P2)
- **HIGH:** неподписанный установщик + доверие только GitHub-digest (P0-1/P0-2).
- **MED:** локальный uvicorn без аутентификации (P2-8); остаточный TOCTOU файла установщика (`%LOCALAPPDATA%` без 0700 на Windows — открывать с share-deny-write); глобальный `--ignore-certificate-errors` + приватные IP в WebView (LAN MITM, частично смягчено отсутствием `js_api` у окон панелей).

### Открыто (мелкое, некритичное)
- Неотрроттленные сохранения настроек (POST на каждый `change`, ответы вне очереди).
- WebView2-флаг через `setdefault`; игнор кода выхода WebView2-бутстрапера в installer.
- hover-rAF не отменяется при внешнем teardown графика; потеря фокуса строки при виртуальном скролле; неотменяемые in-flight fetch; O(n)-пересканы в горячих путях; повторная простановка автозапуска.

### Проверено и чисто
XSS (экранирование + Jinja autoescape), path traversal (архивы/FTP/удаление профиля), HMAC перед pickle, SSRF discovery, sqlite (ro + закрытие в finally), ресурсы/локи/кэши, корректность разбивки на модули (нет циклов, общий `state`, точки monkeypatch).
