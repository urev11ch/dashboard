## P0 — Тихие обновления (довести до ума)
Порядок важен: сначала подпись, потом per-user.

1. **Подпись установщика и .exe (Authenticode).** Убирает SmartScreen и «Издатель: неизвестен» в UAC; без неё любой тихий/фоновый апдейт вызывает подозрение ОС. Сертификат (OV/EV) → секрет `WINDOWS_PFX_BASE64` в CI (шаги `Sign executable`/`Sign installer` уже готовы). — *также закрывает HIGH из ревью.*
2. **Независимая проверка апдейта.** Сверять Authenticode-подпись скачанного `.exe` перед запуском (`WinVerifyTrust`/встроенный ключ) — сейчас доверие держится только на GitHub-digest; при компрометации репо/CI → тихий admin-RCE.
3. **Per-user установка + фоновое обновление** (вернуть `fc1bb53`, доработать). Тест на живой Windows: тихая установка без UAC, миграция/сосуществование со старой Program Files-копией, перезапуск. Явно решить миграцию (оставлять старую копию для отката vs. снимать).

## Находки ревью (дыры/баги/оптимизация)

### Исправлено
Итерация 1 (поверхностный проход):
- `open_ftp_workspace`: `create_ftp_workspace` вне try → 500 при сбое диска/прав → теперь `state.error`+303.
- Скрытый поллер `/api/update/job` после закрытия «Настроек» → отменяется по токену `settingsOpenId`.
- CR/LF в именах файлов FTP (инъекция в `RETR`/`MDTM`) → отсекаются в `_ftp_list_entries`.
- `ValueError`/`LimitOverrunError` из баннера discovery → 500 → теперь ловятся.
- Затенение модуля `config` локальной переменной в роутах FTP → переименовано.

Итерация 2 (глубокий проход):
- **Порог разрыва цикла** (`wash_report.py`): мерялся по «дотянутому» `end_ts` → эффективный порог = `max_gap+period`, две мойки склеивались. Добавлено `Segment.last_sample_ts`, разрыв меряется по сырому времени (кэш workspace v6).
- **Осиротевшие `.part-<uuid>`**: `sweep_stale_part_files` подметает брошенные времянки (>30 мин) перед синхронизацией.
- **NLST + запрет SIZE**: имя, похожее на данные (`.db`/архив), теперь классифицируется как файл (не терялось бы как «каталог»).
- **Гонка переименования объектов**: `build_wash_rows` резолвит имя из снимка overrides, а не из мутируемого `cycle.object_name` (нет полу-применённого переименования в списке).
- **Гонка зеркала (MED-HIGH):** per-profile лок записи (`state.mirror_write_lock`) — один писатель на `datalog/<id>` даже при таймауте `join` (зависший поток больше не пишет параллельно с новым джобом → нет битых `.db`). `remove_ftp_profile_dir` тоже ждёт этот лок (а не «текущий» поток) перед rmtree.

### Открыто (крупное — в P0/P2)
- **HIGH:** неподписанный установщик + доверие только GitHub-digest (P0-1/P0-2).
- **MED:** локальный uvicorn без аутентификации (P2-8); остаточный TOCTOU файла установщика (`%LOCALAPPDATA%` без 0700 на Windows — открывать с share-deny-write); глобальный `--ignore-certificate-errors` + приватные IP в WebView (LAN MITM, частично смягчено отсутствием `js_api` у окон панелей).
- **MED:** активный `.db` без SIZE и без роста mtime тихо не докачивается (нет resume); shutdown не джойнит демон-потоки, отмена авто-refresh во время `to_thread` может стартовать джоб на завершении.

### Открыто (мелкое, некритичное)
- `make_cycle_key` обрезает ts до целых секунд (теоретическая коллизия); одно нечисловое значение метрики выбрасывает весь сэмпл; ложный «провал концентрации» при overshoot заполнения; tz заморожен через границу DST.
- `extract_archive_dbs_cached`: финальный `rglob` вне лока → LRU может вытеснить `cache_dir`; LRU может вытеснить sample-side-файлы активного анализа; лок удерживается на I/O по каталогу.
- Неотрроттленные сохранения настроек; `error_reply` рвёт весь FTP-прогон; дубль при миграции старой раскладки; частичные `.db` при срабатывании анти-бомбы.
- WebView2-флаг через `setdefault`; игнор кода выхода WebView2-бутстрапера; hover-rAF не отменяется при внешнем teardown графика; потеря фокуса строки при виртуальном скролле; неотменяемые in-flight fetch; O(n)-пересканы; повторная простановка автозапуска.

### Проверено и чисто
XSS (экранирование + Jinja autoescape), path traversal (архивы/FTP/удаление профиля), HMAC перед pickle, SSRF discovery, sqlite (ro + закрытие в finally), ресурсы/локи/кэши, корректность разбивки на модули (нет циклов, общий `state`, точки monkeypatch).
